# Kwork Assistant Windows Release

*DRAFT — MUST BE VERIFIED ON CLEAN WINDOWS VM.*

Этот архив содержит portable-версию Kwork Assistant для работы на Windows 10/11.

## 1. Что это
Kwork Assistant — это локальный бот-помощник, который:
- Отслеживает новые проекты на Kwork и оценивает их через AI (Ollama).
- Генерирует черновики откликов.
- Синхронизирует сообщения (Chat Mirror) с клиентами прямо в Telegram.

## 2. Что понадобится
- ОС: Windows 10/11 x64
- Аккаунт Kwork
- Telegram

## 3. Скачать и распаковать
1. Скачайте ZIP-архив с программой.
2. Распакуйте архив в удобную папку (например, `C:\KworkAssistant`). ВАЖНО: не запускайте скрипты прямо из архива!

## 4. Установить Ollama
Для работы ИИ-помощника нужна локальная нейросеть.
1. Скачайте и установите **Ollama** с официального сайта: [https://ollama.com](https://ollama.com)
2. Запустите Ollama (иконка появится в трее).

## 5. Создать Telegram Bot
Бот будет писать вам в личные сообщения о новых заказах.
1. Откройте Telegram и найдите официального бота **@BotFather** (с синей галочкой).
2. Отправьте ему команду `/newbot`.
3. Придумайте название (например, `My Kwork Assistant`).
4. Придумайте username, заканчивающийся на `bot` (например, `my_kwork_assistant_bot`).
5. BotFather выдаст вам **HTTP API Token** (длинная строка вида `123456789:ABCDefgh...`). Скопируйте его.

*НЕ нужно использовать сторонние боты вроде "get my id". Ассистент сам определит ваш ID.*

## 6. Запустить setup.ps1
1. Перейдите в папку с распакованной программой.
2. Нажмите правой кнопкой мыши на `setup.ps1` и выберите **"Выполнить с помощью PowerShell"** (Run with PowerShell).
   > Если Windows блокирует запуск скриптов, откройте PowerShell в этой папке и выполните команду: `powershell -ExecutionPolicy Bypass -File .\setup.ps1`
3. Вставьте скопированный токен Telegram бота.

## 7. Ввести Kwork credentials
Следуйте инструкциям на экране для ввода Kwork login, пароля и последних цифр телефона, привязанного к аккаунту Kwork. Пароль при вводе отображаться не будет (это безопасно).

## 8. Telegram owner auto-detection
Скрипт попросит вас:
1. Открыть Telegram и найти своего только что созданного бота.
2. Нажать **Start** (или отправить `/start`).
3. Скрипт увидит ваше сообщение, покажет ваше имя и спросит подтверждение.
4. Нажмите `Y`, если всё верно.

## 9. Скачать Gemma
Скрипт автоматически проверит наличие нужной нейросети (`gemma4:e4b`). Если её нет, он предложит скачать её (около 4-5 ГБ). Подтвердите загрузку (`Y`) и дождитесь завершения.

## 10. Проверить check.ps1
После завершения мастера настройки нажмите правой кнопкой на `check.ps1` -> **"Выполнить с помощью PowerShell"**. 
Скрипт проверит правильность всех настроек. Убедитесь, что все пункты горят зелёным `[OK]`.

## 11. Запустить start.ps1
Нажмите правой кнопкой на `start.ps1` -> **"Выполнить с помощью PowerShell"**.
Откроется окно консоли, и бот начнет работу в фоновом режиме. Не закрывайте это окно!

## 12. Telegram /start
Перейдите в Telegram к вашему боту. Если он ещё не прислал меню, отправьте `/start`.
Готово! Теперь помощник работает.

## 13. Как пользоваться
Все заказы и уведомления будут приходить в Telegram. Нажмите на кнопки под сообщениями, чтобы сгенерировать отклик или посмотреть подробности.

## 14. Как остановить
Просто закройте окно консоли или нажмите `Ctrl+C`.
Также можно запустить `stop.ps1`.

## 15. Как запустить снова
Просто запустите `start.ps1`. Настраивать заново не нужно.

## 16. Где база данных
Вся ваша информация и история хранится в файле `data/kwork-assistant.db`.

## 17. Где логи
Файлы отладки можно найти в папке `logs/`.

## 18. Backup
Для резервного копирования достаточно скопировать папку `data` и файл `.env`.

## 19. Troubleshooting
Если что-то не работает:
- Убедитесь, что запущен Ollama.
- Запустите `check.ps1`, чтобы узнать, в чём проблема.
- Проверьте правильность `.env` файла.
- Если модель очень долго загружается при холодном старте (более 5 минут) и бот падает, вы можете увеличить параметр `AI_PREWARM_TIMEOUT_SECONDS` (по умолчанию 300) в файле `.env`.
