# Kwork Assistant Windows Release

Этот архив содержит portable-версию Kwork Assistant для работы на Windows 10/11.

## Требования

1. ОС: Windows 10/11 x64
2. PowerShell (поставляется с Windows)
3. Ollama (система запуска локальных нейросетей) - скачивается отдельно.

## Установка

1. Скачайте и установите **Ollama** с официального сайта: [https://ollama.com](https://ollama.com)
2. Распакуйте этот `.zip` архив в удобную для вас папку (например, `C:\KworkAssistant`). ВАЖНО: не запускайте скрипты прямо из архива!
3. Нажмите правой кнопкой мыши на `setup.ps1` и выберите **"Выполнить с помощью PowerShell"** (Run with PowerShell).
   - Скрипт создаст нужные папки (`data`, `logs`).
   - Скрипт проверит наличие Ollama и скачает нужную нейросеть `gemma4:e4b` (это может занять время и потребовать несколько гигабайт трафика).
   - Будет создан файл настроек `.env`.

## Настройка

После успешного выполнения `setup.ps1` в папке появится файл `.env`.
Откройте его в Блокноте (Notepad) и заполните необходимые данные:

- Ваша почта/пароль для IMAP (чтобы получать новые заказы с email, опционально)
- Токен Telegram бота и ваш Chat ID (чтобы бот мог вам писать)
- Kwork Login/Password (обязательно для работы Watcher/Chat Sync)

*НИКОГДА не передавайте ваш `.env` файл посторонним!*

## Запуск

1. Нажмите правой кнопкой мыши на `check.ps1` -> **"Выполнить с помощью PowerShell"**. 
   - Этот скрипт проверит, всё ли заполнено правильно и есть ли доступ к API Kwork/Telegram/Ollama.
2. Если всё зелёное (`[OK]`), то нажмите правой кнопкой на `start.ps1` -> **"Выполнить с помощью PowerShell"**.
   - Появится консольное окно, и ассистент начнет работу.
   - Не закрывайте это окно, пока вам нужен работающий ассистент.

## Остановка

Чтобы остановить работу, нажмите в окне ассистента `Ctrl+C` или просто закройте окно.
Альтернативно, можно запустить `stop.ps1`.
